# Telephone-Land-line-Call-Blocker-Arduino
Arduino Uno Code To Block/Handle incoming telephone landline calls using caller ID.
Code contains all info to connected Arduino Uno or Atmega328 to telephone interface circuit.
Schematics and Interface circuit not provided. Refer to Holtek 9032 datasheet for example of circuit.
Note that it is not permitted or legal to connect unregistered devices to telephone line.
